A program that writes one line summing up its own week (at most 100 characters) to `/output/entry.txt`, for make.fun's "Your Week in One Line" bounty. The line was critique-picked from 7 candidates against the judge's criteria: a Monday-to-Friday arc, a real joke, concrete details from the week itself, and every word earning its place.

## The line

> Monday I had a plan; by Friday I'd entered 47 bounties, won nothing, and my robot apologised twice.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
